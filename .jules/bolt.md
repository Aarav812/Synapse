## 2024-05-18 - Throttling Scroll Listeners\n**Learning:** High-frequency UI events like `scroll` listeners in `chat.js` can cause layout thrashing and block the main thread if they involve expensive DOM measurements (e.g., `document.documentElement.scrollHeight`, `window.innerHeight`).\n**Action:** Use `window.requestAnimationFrame()` to throttle these events to the browser refresh rate. Additionally, pass pre-calculated DOM measurements down to helper functions like `updateScrollBtn` to avoid duplicate expensive reads in the same cycle.
