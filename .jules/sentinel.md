## 2024-05-15 - [XSS Fix] escapeHtml uses DOM\n**Vulnerability:** XSS vulnerability in `escapeHtml` function.\n**Learning:** The `escapeHtml` function used `div.textContent = text; return div.innerHTML;`, which successfully escapes `<` and `>`, but fails to escape single and double quotes. If the return value is used in an HTML attribute context, it can lead to XSS. This is a common pitfall.\n**Prevention:** Rely on regex-based replacements (like replacing `<` with `&lt;` and `"` with `&quot;`) to thoroughly encode all potentially dangerous HTML entities.
