## 2024-07-21 - Icon-Only Button Ligatures Needs Explicit ARIA Labels
**Learning:** Found a specific accessibility issue pattern across this app's UI elements: the usage of Material Symbols ligatures inside icon-only buttons (`<span class="material-symbols-outlined">close</span>`) without explicit `aria-label`s on the parent `<button>`. This results in screen readers reading the raw ligature text ("close") without context of *what* is being closed, which can be highly confusing in multi-modal interfaces.
**Action:** When implementing new icon-only buttons using Material Symbols ligatures, always add an explicit context-aware `aria-label` to the `<button>` (e.g. `aria-label="Close chat history"`) and apply `aria-hidden="true"` to the inner `<span>` to prevent redundant/conflicting screen reader output.
